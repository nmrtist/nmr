# Contributing

Bug reports, documentation improvements and focused pull requests are welcome.
The maintained [contribution guide](docs/src/content/docs/contributing.md)
covers development setup, architecture, build/test commands, documentation
maintenance, scientific evidence and pre-release changes. It is also available on the
[documentation site](https://nmr.nmrtist.space/contributing/).

Start with Rust 1.85 or newer and run `cargo build --locked` from the repository
root. See the [test guide](tests/README.md) for focused targets and the
[CI workflow](.github/workflows/ci.yml) for the complete checks.

Open an [issue](https://github.com/nmrtist/nmr/issues) with a reproducer and expected
behavior, or submit a focused [pull request](https://github.com/nmrtist/nmr/pulls)
explaining the change and its validation. Discuss larger changes first.
Contributions are accepted under MIT OR Apache-2.0.
